# Pagine d'errore

File `src/pages/errors/ErrorPages.tsx`. Una riga su cosa è successo e un solo bottone per uscirne.

| Pagina | Rotta | Azione |
|---|---|---|
| Pagina non trovata | qualunque rotta sconosciuta | Torna alla home (la dashboard del ruolo, o l'accesso) |
| Accesso negato | `#/accesso-negato` | Torna alla home |
| Sessione scaduta | `#/sessione-scaduta` | Accedi di nuovo |
